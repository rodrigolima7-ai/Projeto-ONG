## Interatividade JavaScript
A página `cadastro.html` usa `js/script.js` para máscaras de CPF, telefone e CEP, validação dos dígitos verificadores do CPF, data de nascimento, contador de caracteres e feedback acessível.

**Aviso:** formulário demonstrativo, sem backend, persistência ou transmissão de dados. Não usar para coletar dados pessoais reais em produção. Para recebimento de cadastros é necessário backend seguro, HTTPS, política de privacidade e tratamento adequado conforme LGPD.
